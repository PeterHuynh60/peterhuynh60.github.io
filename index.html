Leaving Firebase for a self-hosted stack

3 dashboards moved onto hardware I own
The problem

The dashboards depended on Firebase (Firestore, Auth, Cloud Functions) and GitHub Pages, tying them to third-party services, quotas and pricing.

What I did

Stood up PocketBase as one shared auth and database backend, with migration scripts that moved the data and rebuilt the schema with per-collection access rules. Replaced Cloud Functions with a small Node service that calls the Claude and Google Maps APIs behind PocketBase login, so API keys never reach the browser, and moved the sites into Nginx containers with automatic HTTPS.

Result

One login system and full control over data, backups and access.

Taming a 200+ mod Minecraft server

213 mods, one stable server
The problem

Friends wanted a heavily modded Create: Aeronautics pack. Out of the box it wouldn't start: the container shipped the wrong Java version, files had the wrong owner, and the world crashed on startup.

What I did

Installed Java 21 inside the container and pointed the server at it, fixed file ownership for the container's user, and moved the server off a port that was already taken. Then traced crashes to performance mods (Moonrise, C2ME, Radium) conflicting with Create and the claims mod and removed them, including one a case-sensitive filename let slip past the first cleanup. Memory is tuned in Crafty's launch command, the one setting that actually applies.

Result

A stable, whitelisted server friends can join anytime, managed from a web panel.
